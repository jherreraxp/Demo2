📝 Palabras por juego

Escribe las palabras que quieres que salgan en cada juego y graba cómo se dicen. Las sílabas se separan solas (puedes corregirlas). En la Carrera y el Bosque, si la palabra no tiene modelo 3D se muestra su dibujo.

🔊 Efectos de sonido

Cambia cualquier efecto por uno tuyo: sube un archivo de sonido (mp3, wav, ogg) o grábalo. Puedes ponerlo para todos los juegos o solo para uno.

Sitios para descargar efectos gratis

  • Pixabay · Efectos de sonido — gratis, sin registrarse
  • Mixkit · Free Sound Effects — gratis, muy buena calidad
  • Freesound — enorme; busca licencia CC0
  • ZapSplat — gratis con registro
  • OpenGameArt · Sonidos — para juegos, CC0 y libres
  • Kenney · Audio — CC0, los que usa el juego
  • Sonniss GDC Bundle — gigante y libre de regalías
  • MyInstants — botones divertidos (revisa la licencia)

Consejo: para "Acierto" busca success o win; para "Popó" busca fart o squish; para "Aplausos" busca kids cheering.

🌐 Publicar en la web

Publica la configuración (palabras, canciones, nombres), las voces de las palabras y tus efectos para que estén en todos los dispositivos. Necesitas la llave de GitHub (se crea una vez en github.com/settings/personal-access-tokens/new, con acceso solo a y permiso Contents: Read and write).
