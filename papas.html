Sesión y voz

Grabar los sonidos con tu voz

Graba cada sonido (no el nombre de la letra): para la m di "mmmm", para la s "ssss", para la p di "pa". Si un sonido no está grabado, el juego usa la voz del dispositivo.

Las grabaciones se guardan en este navegador. Para que suenen en todos los dispositivos, toca Exportar grabaciones y envía el archivo; se publica en el juego (carpeta assets/voz/).

No se pudo usar el micrófono. Revisa el permiso del navegador para este sitio.
